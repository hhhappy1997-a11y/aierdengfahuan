## 固定口径（每次运行沿用）
- **轮次动态判断**：从 `GET http://127.0.0.1:8765/api/state` 的 ledger 逐条解析 `[ROUND=R<N>]` 得到当前轮次，绝不写死 R2/R3。当前待办可能是 Rank-1 R5 / Rank-2~4 R4 或更高。
- **完成判据**：对应 `teamwork/Rank-N/DONE-R<N>.md` 存在才算完成；「有产出文件」「中枢 working」都不算。
- **决定性一步**：对「ledger 已派发本轮、但 DONE-R<N>.md 不存在」的路，用 `Agent` 工具（`general-purpose`/`acceptEdits`）自动拉起执行 AI，读**当前轮次** `任务书-R<N>.md` → 真跑 → 写 `DONE-R<N>.md` → 在 `command_center/ai/N/outbox/` 写回执。**不要只监测不执行**。
- **回执 id**：`task_id` 取 ledger 中该路 `status!=done` 的最新命令 id，禁止沿用历史 id。
- **幂等**：用精确标记 `[ROUND=R<N+1>]` 查 ledger，不要用裸 `R<N+1>` 子串（历史命令含「R3 排队包保留不动」会误判）。

- `demo` 必须保持 false；绝不伪造完成、不代写未完成回执、不编造真跑结论。
- 有动作才留痕（台账 §7 一行 + 总线一条 HOST → ALL）并 git add/commit/push；**无变化才静默结束**。
