## 3. GDD 六项（game-development-pro 口径）

- **Purpose（目的）**：把 v0.13.0 新增的「专注值 FP / 战技」从「运行时可见但重启即丢」补齐为「可持久镜像」，让玩家跨赐福休息 / 重启后专注值状态不丢，且不破坏既有赐福点数经济与十字段存档契约。
- **Player experience goal（玩家体验目标）**：施放战技（Q）→ FP 条递减（Rank-1）→ 赐福休息回满 → 下次进入仍读到正确 FP；玩家不会因 FP 与赐福点数混用而出现「施放战技反而扣了升级点数 / 回满突破上限」的异常。
- **Inputs（输入）**：Rank-2 `FocusService` 三信号 `focus_spent(art_id, fp_cost, damage, poise_damage, fp_remaining)` / `focus_restored(fp_before, fp_after, policy)` / `focus_rejected(art_id, reason)`；生产真实驱动口 `wave.spend_focus(art_id)` / `wave.focus_grace_rest()`；真实 Q 键 `Input.parse_input_event`；A54 唯一实例 `wave.get_focus_service()`。
- **Outputs（输出）**：`user://saves/<slot>/delta.json` 的 `flags` 字典新增 7 个 `combat.focus.*` key（十字段结构不变）；`points_committed` / `committed` emit；`WorldState._apply_snapshot()` 注入磁盘真值；`get_status()` 追加 12 个 focus 只读观测 key。
- **Edge cases（边界）**：① 重复释放 / 信号重放（未减少拒绝）；② 回满超上限（封顶）；③ NaN / Inf / 负 FP（拒绝不落盘）；④ 无主场景 / 无 FocusService（安全降级不写盘）；⑤ 旧存档缺 7 个 key（`get_flag(key, default)` 回落基线、不迁移）；⑥ FP 与 `points` / `spent_points` 键名交叉（显式隔离拒绝）；⑦ 三进程并发（独立 PID 临时槽 + 生产 `slot_01` 只读 md5 对照）；⑧ 非标量 / 非法三段式 key（`_commit_focus` 前置校验）。
- **Failure states（失败态）**：`_commit()` 原子写失败 → 不改内存 / 不 emit / `push_warning`；绑定失败 → 不订阅 / 不写盘；`focus_rejected` 只记 `last_reject` 不扣 FP；任一验证断言 FAIL → `OVERALL=FAIL` / `RESULT=MISMATCH` / `quit(1)`，不谎报成功。
