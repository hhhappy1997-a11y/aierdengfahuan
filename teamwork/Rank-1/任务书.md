## 4. `架构设计.md` 必写要点

1. **渲染链路**：SubViewport 低分辨率渲染 → Nearest 放大 → 主 viewport；像素→米缩放公式（如 32px = 1m）；底部中心锚定（脚贴地）；自定义 AABB 防屏幕边缘剔除；遮挡排序策略。角色用 `Hybrid2D3DSprite` / `Hybrid2D3DAnimatedSprite` 思路，**不自己造 billboard**。
2. **光照与 FX 挂点**：DirectionalLight3D 暖金主光 + 冷色环境/阴影；体积光 / 光尘 / 湿地倒影 / bloom 的挂点、开关、性能分级（对齐 4 号视觉规范，但不要越界写美术工作流）。
3. **chunk 流式加载状态机**：以玩家所在 chunk 为中心 3x3 常驻；`ResourceLoader.load_threaded_request` / `load_threaded_get_status` / `load_threaded_get` 完整时序；防重复加载、加载中/已加载/卸载三态去重、卸载延迟；区域边界藏在悬崖 / 升降机 / 地道。
4. **性能预算表**：chunk 尺寸、常驻 chunk 数、加载线程数、目标帧时间、内存上限、M2「性能监视器无 spike」的验收口径。
5. **存档对接（I-1）**：只经 `WorldState.get_flag(key, default)` / `set_flag(key, value)`，**不得直接读写存档文件或 SaveDelta**。
6. **密度原则**：每 30 秒路程 1 个 POI 的落地方式。
