## 2. I-1：存档对接（3 号 → 1 号）

**唯一允许的两行代码形态**（`chunk_streaming.gd`）：

```gdscript
var ws: Node = get_node_or_null("/root/WorldState")
flags[key] = ws.call("get_flag", key, null)
```

| 约束 | 1 号实现 |
|---|---|
| 不直接读写存档文件 | 代码中无 `FileAccess` / `ConfigFile` / `user://` / `JSON.stringify` 落盘 |
| 不构造 SaveDelta | 代码中无 `SaveDelta` 字样与结构 |
| 不定义 flag schema | 键名由 chunk 实例自己通过 `get_flag_keys()` 声明，1 号只负责取值与转交 |
| 3 号单例缺失时不阻塞 | `get_node_or_null` + `has_method` 双重检查，缺失时不发错误、只 `push_warning` 并使用空 flags |

**chunk 实例可选实现的鸭子接口**（由 3 号的 chunk 场景提供，1 号不强制、不定义）：

| 方法 | 返回 | 语义 |
|---|---|---|
| `get_flag_keys()` | `Array[String]` | 本 chunk 关心的 flag 键名列表，遵守三段式 `<模块>.<对象>.<状态>` |
| `apply_world_flags(flags: Dictionary)` | `void` | 由 3 号把已变化的 POI 状态应用到场景（开过的宝箱、点亮的赐福等） |
| `get_poi_count()` | `int` | 供 1 号做密度校验，纯读 |

> 建议键名形状 `world.chunk_limgrave_0_0.chest_01_opened`，**仅为建议**，最终 schema 归 3 号，已列入待裁决项。

## 3. I-4：渲染封装（1 号 → 2 号）

**对外节点**：`res://scenes/Main.tscn` 中 `Player/Hybrid2D3DAnimatedSprite`（脚本 `res://scripts/render/hybrid_2d3d_animated_sprite.gd`）。

| 暴露给 2 号 | 签名 | 说明 |
|---|---|---|
| **唯一玩法接口** | `set_pose(pose_name: String, frame_index: int) -> void` | `pose_name` 用 4 号 `import.json` 的动作名（`idle` / `walk` / `roll` / `attack` …）；`frame_index` 可强制锁帧 |
| 只读查询 | `get_current_pose() -> String` / `get_current_frame() -> int` | 2 号可用于状态机自测，不影响渲染 |
| 只读信号 | `pose_changed(pose_name: String, frame_index: int)` | 2 号可订阅做音效 / 判定对齐 |

**2 号禁止事项**（契约硬约束）：不写 billboard、不写脚底锚定、不写 AABB 剔除、不自己换算像素→米、不直接操作 `Sprite3D` / 扩展节点。需要新动作时向 4 号提 `import.json` 动作名，1 号只做参数回填，不改接口。

**1 号自己也不实现**上述算法：缩放 / 锚定 / AABB 由 `Hybrid2D3D-Renderer` GDExtension 提供，1 号脚本只做转发、帧尺寸应用与参数配置。扩展未装入时用内置 `Sprite3D` 占位，M0 仍能跑通「脚贴地 + 像素清晰」。

**帧尺寸来源**：`set_frame_profile(frame_size: Vector2i)` 是给 1 号导入流程用的回填入口，供 4 号 `import.json` 驱动，2 号不调用。

## 4. I-5：资产导入（4 号 → 1 号）

| 4 号交付 | 1 号消费方式 | 落点 |
|---|---|---|
| `res://assets/generated/chars/*.png` spritesheet | 按 `import.json` 的 `action` / `frame_count` 切帧，生成 `SpriteFrames`；`set_frame_profile(frame_size)` 回填锚定 | `PixelSprite` / 扩展节点 |
| `res://assets/generated/backdrops/*.png` | 挂 `BackdropFar` / `BackdropMid`，按 0.15 / 0.4 跟随系数做视差 | `SubViewport` 内 |
| `res://assets/generated/fx/glow.png` + 水面遮罩 | 光尘粒子贴图、湿地倒影扰动遮罩 | `FXLayer/LightDust` / `WetReflection` |
| `res://assets/generated/props/*.png` | 3D 世界中的像素道具精灵 | chunk 场景 |
| `import.json` | 读取 `frame_size` / `anchor` / `frame_count` / `action_names` 四个字段 | 导入期一次性处理 |

**导入硬规范**（见 `目录与命名规范.md` §4.1）：lossless（`compress/mode=0`）、`mipmaps/generate=false`、节点 `texture_filter=0`（Nearest）。三条缺一，M0「像素清晰」不通过。

**降级**：4 号资产未到位时，M0 用程序化 `_draw()` 占位（零外部依赖）验证渲染链路；占位角色只验证锚定与缩放，不参与成片美术判断。1 号不写 4 号目录下的任何文件。
