## 3. autoload 单例表

| 单例名 | 脚本 `res://` 路径 | 归属工位 | 职责 | 1 号是否可依赖 |
|---|---|---|---|---|
| `WorldState` | `res://scripts/world/world_state.gd` | **3 号** | `get_flag(key, default)` / `set_flag(key, value)`；flag schema 与 SaveDelta 由其定义 | 是，仅经 I-1 |
| `GameEvents` | `res://scripts/core/game_events.gd` | **待裁决**（契约未指定；建议 3 号或主 AI 定） | 全局信号总线（`enemy_defeated` 等跨模块中转） | 否，M0~M2 不依赖 |
| `SaveSystem` | `res://scripts/world/save_system.gd` | **3 号** | Delta 持久化、存读档 | 否，1 号禁止直接访问 |
| `ChunkManager` | `res://scripts/world/chunk_streaming.gd` | **1 号** | 3×3 流式加载、`set_player_chunk`、区块状态 | 是（本工位产出） |
| `SceneRouter` | `res://scripts/core/scene_router.gd` | **1 号** | 场景切换、加载边界（升降机/地道）、画质档位切换 | 是（M1 交付） |

`project.godot` 对应片段：

```
[autoload]

WorldState="*res://scripts/world/world_state.gd"
GameEvents="*res://scripts/core/game_events.gd"
SaveSystem="*res://scripts/world/save_system.gd"
ChunkManager="*res://scripts/world/chunk_streaming.gd"
SceneRouter="*res://scripts/core/scene_router.gd"
```

**重要实现约束**：autoload 脚本**不要**声明 `class_name`（尤其 `chunk_streaming.gd` 不能写 `class_name ChunkManager`）。Godot 4 中 autoload 单例名与全局脚本类同名会冲突并导致启动报错。跨文件引用一律用 `get_node("/root/ChunkManager")` 或 `ChunkManager.xxx()` 单例形式。

**加载顺序**：`WorldState` 必须排在 `ChunkManager` 之前，保证 chunk 加载时 `get_flag` 已可用；`SceneRouter` 最后，它依赖前两者的存在性检查。

## 4. `project.godot` 关键配置项

```
[application]

config/name="艾尔登法环 · HD-2D"
run/main_scene="res://scenes/Main.tscn"
config/features=PackedStringArray("4.2", "GL Compatibility")
config/quit_on_go_back=false

[display]

window/size/viewport_width=1280
window/size/viewport_height=720
window/size/window_width_override=1280
window/size/window_height_override=720
window/size/resizable=true
window/stretch/mode="canvas_items"
window/stretch/aspect="keep"
window/vsync/vsync_mode=1

[rendering]

renderer/rendering_method="gl_compatibility"
renderer/rendering_method.mobile="gl_compatibility"
textures/canvas_textures/default_texture_filter=0
2d/snap/snap_2d_transforms_to_pixel=true
2d/snap/snap_2d_vertices_to_pixel=true
anti_aliasing/quality/msaa_2d=0
anti_aliasing/quality/msaa_3d=0
```

要点说明：

1. `textures/canvas_textures/default_texture_filter=0` → 项目级默认 **Nearest**（Godot 4 枚举 `TEXTURE_FILTER_NEAREST = 0`），这是像素硬边的总开关。
2. **键名校正**：1 号任务书 §3 字面写的是 `rendering/textures/canvas_items/default_texture_filter=0`，Godot 4 实际合法键为 `rendering/textures/canvas_textures/default_texture_filter`（在 `[rendering]` 段内即 `textures/canvas_textures/...`）。本文件按**引擎合法键**落地，字面差异已列入 `README.md` 待主 AI 裁决。
3. `config/features` 的小版本仅为示例占位，**以本机实际安装的 Godot 4 小版本为准**，1 号不做版本声明、不擅自升级引擎。
4. `window/stretch/aspect="keep"` 保证 16:9 比例不变，配合 `stretch_shrink` 才能维持整数倍像素放大；改 `expand` 会破坏像素栅格。
5. `msaa_2d/msaa_3d = 0`：MSAA 会把像素边缘糊掉，HD-2D 下必须关。
6. `2d/snap/* = true`：2D 叠加 FX（光尘）对齐到整数像素，避免与 3D 像素栅格错位。

### 4.1 像素图导入设置（`.import` 参数，1 号给规范、4 号套用）

Godot 4 的 PNG `.import` 中必须：

```
[params]
compress/mode=0              # 0 = Lossless，禁止有损压缩
mipmaps/generate=false       # 关闭 mipmaps，远处轮廓不糊
process/fix_alpha_border=true
process/premult_alpha=false
process/size_limit=0
```

节点侧再确认 `texture_filter = 0`（Nearest）。这三条（lossless / 无 mipmaps / Nearest）缺一，M0「像素清晰」验收即不通过。资产导入由 4 号执行，1 号不写 `assets/` 下任何文件。

`project.godot` 的 `[input]` 段序列化格式较繁（`Object(InputEventKey, "physical_keycode":87, ...)`），**建议由 Godot 编辑器 Input Map 面板按上表生成后回填**，避免手写字段与本机小版本不一致。以下为单个 action 的合法示例，供校验格式用：

```
[input]

move_up={
"deadzone": 0.2,
"events": [Object(InputEventKey,"resource_local_to_scene":false,"resource_name":"","device":-1,"window_id":0,"alt_pressed":false,"shift_pressed":false,"ctrl_pressed":false,"meta_pressed":false,"pressed":false,"keycode":0,"physical_keycode":87,"key_label":0,"unicode":0,"location":0,"echo":false,"script":null)
```
