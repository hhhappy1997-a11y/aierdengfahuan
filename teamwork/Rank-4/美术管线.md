# 美术管线 v1.0（4 号工位 · ComfyUI 像素资产生产）

> 结论先行：美术生产是**两条可 API 调用的本地 ComfyUI 工作流**（基础动画 W1→W3、装饰分层 W4→W5），加一套**第一天就冻结的风格约束**（IP-Adapter + LoRA + ControlNet、固定 Prompt 骨架、种子锁定）。AI 只负责产能，出的是底稿；主角 / Boss / 关键场景必须在 Aseprite 人工精修后才能入工程。
> **零付费 / 零外部依赖**：只用本地已装模型，不引入任何外部素材生成服务。总纲第 6 节的「云 ComfyUI」分支**按项目既定决策已废弃**，替代方案见 §7 本地显存分级降级表。

---

## 1. 两条管线总览

```text
管线 1（基础动画）
  角色基准图 + OpenPose 骨架 + 风格锚点
        │
        ▼
  [W1] 姿态编辑  Qwen-Image-Edit / 图生图 + 三层约束
        │  W1_pose_edit_*.png（高清 RGBA）
        ▼
  [W2] 图生视频  AnimateDiff / I2V 补帧
        │  W2_i2v_frames_*.png（8 帧序列）
        ▼
  [W3] 精灵表拼接 + 降采样 + 16 色量化
        │  idle / walk / jump 横向等尺寸帧条
        ▼
  assets/generated/chars/*.png + import.json

管线 2（装饰分层）
  W2 基础视频 + 装饰参考图 + 装饰 mask
        │
        ▼
  [W4] 局部重绘  只在 mask 内重绘，LayerDiffuse 出 RGBA
        │  W4_decor_*.png
        ▼
  [W5] 装饰精灵表  与 base 同尺寸/帧序/坐标系/seed/降采样参数
        │  hair / eyes / cloth 独立 RGBA 层
        ▼
  assets/generated/decor_layers/*.png + import.json(aligned_with 必填)
```

两管线**共用同一份 `prompt_skeleton.json` 与同一个 seed 派生规则**，这是风格不漂移的前提。

## 2. W1~W5 节点级说明

### 2.1 管线 1

| 节点 | 输入 | 关键 ComfyUI 节点 | 关键参数 | 输出 | 质量闸门 |
|---|---|---|---|---|---|
| **W1 姿态编辑** | 角色基准图 `char_base.png`、OpenPose 骨架 `pose_<action>_<frame>.json`、风格锚点 `style_anchor.png`、固定 Prompt 骨架（只换 `[SUBJECT]`） | `CheckpointLoaderSimple` → `LoraLoader`(pixel-art-lora) → `CLIPTextEncode` ×2 → `IPAdapterAdvanced` → `ControlNetLoader` + `OpenposePreprocessor` + `ControlNetApplyAdvanced` → `LayeredDiffusionApply` → `KSampler` → `VAEDecode` → `SaveImage` | LoRA 0.8；IP-Adapter weight 0.7；ControlNet weight 0.9 / end 0.8；LayerDiffuse weight 1.0；steps 28 / cfg 7.0 / denoise 0.55；512×512；seed 由 §5.3 派生 | `W1_pose_edit_00001.png`，高清 RGBA 透明底 | alpha 通道存在；非主体区 alpha=0；姿态骨架与参考误差可视化通过；色板落在 32 色表内 |
| **W2 图生视频** | W1 输出单帧、动作描述（不进 Prompt 骨架，只进运动参数）、frame_count | `LoadImage` → `AnimateDiffLoaderSD15`（或等价 I2V 节点）→ 帧序列生成 → `SaveImage` | context_length 16；frame_count 8（idle 4 / walk 8 / jump 6）；fps 8；motion_bucket_id 80；seed 沿用 W1 | `W2_i2v_frames_0001..0008.png` | 帧数达标；主体不形变；相邻帧位移 ≤ 2px（32px 基准）；无闪帧 |
| **W3 精灵表拼接** | W2 帧序列 | `SpritesheetAssembler`（自定义）+ ImageMagick 后处理 + Aseprite 人工修帧 | frame 32×32；columns = 帧数；rows = 1（横向帧条）；Point 降采样；16 色量化；dither None；anchor (16,31)；PNG32 RGBA | `<subject>_<action>_v1.png` + `import.json` | 每帧严格等尺寸；脚底 Y 恒定；无抗锯齿；命名合规；色数 ≤ 16 |

**产出帧条规格**：`idle` 4 帧 / `walk` 8 帧 / `jump` 6 帧，均为**横向等尺寸帧条**（`columns = 帧数, rows = 1`），统一 8 fps，idle/walk 循环、jump 不循环。

### 2.2 管线 2

| 节点 | 输入 | 关键 ComfyUI 节点 | 关键参数 | 输出 | 质量闸门 |
|---|---|---|---|---|---|
| **W4 局部重绘** | W2 基础视频帧、装饰参考图（`decor_ref_hair/eyes/cloth.png`）、装饰区域 mask（`decor_mask_*.png`） | `LoadImage` ×3 → `VAEEncode` → `SetLatentNoiseMask` → `LayeredDiffusionApply` → `KSampler` → `VAEDecode` → `RGBAAlphaMask` | denoise **0.45**（低于 W1，防止破坏 base 结构）；**seed 与 base 完全相同**；mask 外 alpha 强制 0；LoRA / IP-Adapter / ControlNet 组合与 W1 一致 | `W4_decor_<layer>_*.png` | mask 外必须全透明（alpha=0）；装饰与 base 主体结构不冲突 |
| **W5 装饰精灵表** | W4 序列 | `SpritesheetAssembler` + 同一套降采样参数 | frame 32×32、columns/rows/anchor/Point/16 色/PNG32 **全部与 base 一致** | `<subject>_<layer>_v1.png` + `import.json`（`layer_type=decor`、`aligned_with` 必填） | **逐像素对齐**：与 base 同尺寸、同帧序、同坐标系、同 seed、同降采样参数；叠加后无 1px 偏移；禁止运行时校准 |

**装饰层清单**：`hair`、`eyes`、`cloth` 三个独立 RGBA 层。运行时由 1 号按 I-5 清单叠加，**不得在运行时做偏移校准**——对齐是生产阶段的责任。

### 2.3 节点依赖与自定义节点说明

- 标准节点：`CheckpointLoaderSimple` / `LoraLoader` / `CLIPTextEncode` / `LoadImage` / `ControlNetLoader` / `ControlNetApplyAdvanced` / `KSampler` / `VAEDecode` / `VAEEncode` / `SetLatentNoiseMask` / `SaveImage` / `EmptyLatentImage`。
- **第三方/自定义节点（需 M0 真跑用 `/object_info` 校准实际类名与入参）**：`IPAdapterAdvanced` + `IPAdapterModelLoader` + `CLIPVisionLoader`（IP-Adapter 套件）、`OpenposePreprocessor`（ControlNet 预处理）、`LayeredDiffusionApply`（LayerDiffuse）、`AnimateDiffLoaderSD15` / I2V 补帧节点、`SpritesheetAssembler`、`RGBAAlphaMask`。
- §3 的工作流 JSON 中上述自定义节点的**类名与输入名以本地实际安装版本为准**；提交前用 `GET http://127.0.0.1:8188/object_info` 核对一次即可，不写任何探针脚本。若本地未安装某节点，按 §7 降级表处理。

## 4. 像素风格锁定：具体参数

### 4.1 LoRA（固定画风）

| 项 | 值 |
|---|---|
| 模型 | `Limbicnation/pixel-art-lora` → 本地 `models/loras/pixel-art-lora.safetensors` |
| 触发词 | `pixel art, pixel-art style`（写进正向提示词末尾） |
| 权重 | `strength_model = 0.8`、`strength_clip = 0.8`（允许 0.7~0.9，同批次内必须一致） |
| 约束 | 所有品类、所有批次必挂，不允许单张关闭 |

### 4.2 ControlNet OpenPose（姿态锁定）

| 项 | 值 |
|---|---|
| 模型 | `control_v11p_sd15_openpose.pth` |
| 预处理器 | `OpenposePreprocessor`，`detect_body=enable`、`detect_hand=disable`、`detect_face=disable` |
| 参数 | `strength 0.9`、`start_percent 0.0`、`end_percent 0.8` |
| 骨架文件 | `res://assets/generated/chars/_pose/<action>_<frame>.json`，同一动作**跨角色复用同一份骨架** |
| 约束 | 姿态骨架库冻结后不得逐角色微调，否则动作风格漂移 |

### 4.3 LayerDiffuse（透明底 RGBA）

| 项 | 值 |
|---|---|
| 方法 | `SD15 Attention Injection (transparent)`，`weight = 1.0` |
| 输出 | RGBA，主体外 alpha=0，**省掉抠图** |
| 校验 | 出图后检查 alpha 通道存在、非主体区 alpha 全 0；装饰层 mask 外强制 alpha=0（`RGBAAlphaMask`） |
| 约束 | 禁止用洋红/绿幕纯色底再抠图，会引入边缘杂色 |

### 4.4 降采样（ImageMagick）

生成 512×512 高清图 → 收敛 → Point 降至 32×32 → 16 色量化 → PNG32：

```bash
magick W3_raw.png -alpha on -filter Lanczos -resize 25% \
  -filter Point -resize 32x32! -colors 16 -dither None \
  -define png:color-type=6 PNG32:out_32.png
```

| 参数 | 值 | 理由 |
|---|---|---|
| 一次收敛 | `Lanczos -resize 25%` | 先收细节，避免 Point 直接降采样产生锯齿噪点 |
| 最终降采样 | `Point -resize 32x32!` | 硬边、无插值，保像素颗粒 |
| 色数 | `-colors 16`（`-dither None`） | 对齐 §2.2 的 32 色共享板与 ≤16 色/角色约束；禁抖动，抖动会破坏 1px 轮廓 |
| 格式 | `PNG32` RGBA、lossless | 透明底入图集 |
| 禁止 | `-filter Lanczos` 直接到 32px、`-antialias`、任何模糊 | 会产生半透明脏边 |

### 4.5 Aseprite 手工修帧

| 项 | 值 |
|---|---|
| 画布 | 32×32，索引色 16 色，透明索引 0 |
| 轮廓 | 1px `#0B1226` 闭合，脚底 Y 恒定 31 |
| 逐帧检查清单 | ① 缩小到 10% 剪影可辨 ② 相邻帧位移 ≤ 2px ③ 无孤立抖动像素 ④ 高光 1~2px 且方向一致 ⑤ 色号全在共享板内 ⑥ 装饰层与 base 叠加无 1px 偏移 ⑦ 锚点 (16,31) 未漂移 |
| 帧循环 | idle/walk 首末帧衔接无跳变；jump 不循环 |
| 输出 | Aseprite 导出 PNG 帧条 + `import.json`（帧尺寸 / 动作 / fps / pose_names 见资产契约） |

## 5. 风格一致性三层约束（第一天就搭好，不许后期补救）

| 层 | 手段 | 冻结内容 | 违反后果 |
|---|---|---|---|
| 第 1 层：结构 + 画风 + 姿态 | **IP-Adapter + LoRA + ControlNet 组合** | IP-Adapter `ip-adapter_sd15.bin` + `CLIP-ViT-H-14`，weight 0.7，风格锚点图 `style_anchor.png` 全项目唯一；LoRA 0.8；ControlNet 0.9 共享骨架 | 单张好看但和已有资产不是一套东西 = 拼凑感，判重做 |
| 第 2 层：Prompt | **固定骨架只换 `[SUBJECT]`** | `prompt_skeleton.json` 全字段冻结；positive 中唯一槽位替换主体名；negative / style / lighting / palette / sampling 一律不改 | 措辞微调会造成批次间风格漂移 |
| 第 3 层：随机性 | **种子锁定** | `seed = 20261108 + category_offset*10000 + action_offset*100 + frame_index`；装饰层沿用 base 的 seed；同 seed 跨 prompt 复用；实值写进 `import.json` 的 `seed` 字段 | 装饰层重抽 seed 会破坏逐像素对齐 |

4. D 档下 M0 仍必须能自己上手玩：`_draw()` 占位覆盖多层视差 + 体积光 + 光尘 + 倒影 + bloom + 金线深蓝 UI，验收清单见视觉规范 §8。
5. 任何情况下不引入外部生成服务、不列云服务、不做花费确认。
