# HD-2D 视觉规范 v1.0（4 号工位 · 冻结草案）

> 结论先行：本项目的画面不是「像素风」，而是**像素点阵实体 vs 平滑多层景深**的强对比。角色、道具、UI 走硬边 1px 像素网格，背景、雾、光、倒影走平滑渐变与低分辨率色带；两者必须共用同一套暖金 × 冷夜雾色板，否则就是拼凑感。
> 本文件是美术冻结依据。已确认的色号 / 层数 / 系数不得擅自改动；待主 AI 裁决项见 `README.md`。

## 1. 风格锚点与禁忌清单

| 项 | 锚点 |
|---|---|
| 参考坐标 | 《八方旅人》HD-2D 的构成逻辑：正交/弱透视 3D 地形 + 2D 像素角色 + 景深虚化 + 体积光 + bloom（只取构成逻辑，不复制任何具体角色、场景、UI 资产） |

## 3. 景深分层与视差系数（已冻结）

设计基准分辨率：**640×360 低分辨率渲染缓冲 → 整数倍 Nearest 放大**（3x = 1920×1080）。所有像素实体对齐 640×360 网格，背景层允许平滑渐变。

相机水平位移 `cam_x`，每层水平偏移 `offset_x = -cam_x * parallax`（`round()` 到整数像素）。垂直方向仅 L0/L1 做 0.3 倍补偿，其余不跟随。

| 层 ID | 内容 | 视差系数 | 绘制顺序 | 色温/饱和处理 | 模糊半径(px, 640×360 基准) | Alpha |
|---|---|---|---|---|---|---|
| `bg_0_sky` | 天空渐变、黄金树辉光晕 | 0.05 | 0（最底） | 冷雾偏色，饱和 -40% | 0（连续渐变） | 1.0 |
| `bg_1_far` | 远山、黄金树剪影、废墟轮廓 | 0.15 | 1 | 冷调 `#2B3A5C`，饱和 -55% | 2.0 | 1.0 |
| `bg_2_mid` | 中景林地、建筑、崖体 | 0.35 | 2 | 冷调，饱和 -30% | 1.0 | 1.0 |
| `bg_3_near` | 近景地形、可站立面、湿地 | 0.70 | 3 | 中性，饱和 -10% | 0 | 1.0 |
| `fx_0_back` | 后景体积光、远景光尘 | 0.45 | 4 | 暖金，Add 混合 | 1.5 | 0.25~0.45 |
| `entity` | 角色 / 敌人 / Boss / 道具（**纯像素**） | 1.00（基准） | 5 | 原色板，Nearest，无模糊 | 0 | 1.0 |
| `fx_1_front` | 近景光尘、打击特效、倒影高光 | 1.00 | 6 | 暖金为主，Add 混合 | 0 | 0.30~0.80 |
| `fg_0_occl` | 前景遮挡（草丛、柱、枝叶剪影） | 1.25 | 7 | 压暗至 L1~L2，饱和 -60% | 1.0 | 0.85~1.0 |
| `ui` | 金线深蓝 UI | 0.00（屏幕固定） | 8（最顶） | 原色板 | 0 | 1.0 |

**硬约束**：
- 景深层固定 **7 个背景/特效层 + 1 实体层 + 1 前景层 + 1 UI 层**，M0 阶段即可全部用程序化占位跑通（§7），层数不随区域增减。
- 只有 `entity` 层允许像素硬边；`bg_*` 层禁止出现像素块感，用连续色带/多边形渐变。
- 实体层与背景层之间必须至少有 1 个半透明 `fx` 层做「空气透视」，这是 HD-2D 景深感的关键，不许省。
- 视差系数写死为常量表，由 1 号在渲染侧落地；4 号不产出 `.gd`/`.tscn`。

## 7. 程序化 `_draw()` 占位方案（零外部依赖，M0 可跑通画面）

> 结论：**不依赖任何图片资产、ComfyUI、插件或外部服务**，用单个 `Node2D`/`Control` 的 `_draw()` 即可画出「多层视差 + 体积光 + 光尘 + 湿地倒影 + bloom + 金线深蓝 UI」的完整 HD-2D 画面，让 M0 在正式美术到位前先验证构图、明度层级与景深感。这是视觉占位，不是最终渲染实现；正式资产到位后由 1 号替换为纹理层，此节点保留为调试开关。

### 7.1 绘制分层顺序（一次 `_draw()` 内按序调用）

```
_draw():
  1  bg_0_sky   : 横向色带渐变（N 条 draw_rect，逐条插值）
  2  bg_1_far   : 远山/黄金树剪影 draw_colored_polygon
  3  bg_2_mid   : 中景崖体/林地 draw_colored_polygon
  4  bg_3_near  : 地面带 + 湿地 mask
  5  fx_0_back  : 体积光扇形 + 远景冷白光尘
  6  reflection : 角色/物体剪影垂直镜像（湿地倒影）
  7  entity     : 32×32 像素人形（draw_rect 像素块阵列）
  8  fx_1_front : 暖金光尘 + 同心圆模拟 bloom
  9  fg_0_occl  : 前景草丛/柱剪影
 10  ui         : draw_rect 底板 + 1px 金线描边
```

### 7.2 各层实现思路（只用 `_draw()` 原语）

| 层 | 原语 | 做法 |
|---|---|---|
| 天空渐变 | `draw_rect()` × N | 把画面高度切成 N=64 条水平色带，每条颜色在 `#16233F` → `#2B3A5C` 之间线性插值；色带够密即呈**平滑**渐变（这就是「平滑景深」的来源） |
| 远山剪影 | `draw_colored_polygon()` | 用一组固定顶点画锯齿山形，填 `#2B3A5C`，再叠一层低 alpha 冷雾矩形降低对比；黄金树用细长多边形 + 顶部同心圆辉光 |
| 中景崖体 | `draw_colored_polygon()` | 多边形填 `#4A6089` 与 `#6E6453`，上缘加 1px 亮边模拟受光 |
| 地面 | `draw_rect()` | 地平线以下填 `#29251F`；湿地区域单独用 `#16233F` + 低 alpha 高光条带标记 |
| 体积光 | `draw_colored_polygon()` × 3~5 | 以光源屏幕坐标为顶点，向下扩散的扇形，填 `#FFD27A` 且 alpha 逐层递减（0.18 / 0.12 / 0.07 / 0.04），模拟径向光束衰减 |
| 光尘 | `draw_circle()` × 40~120 | 每粒半径 1，位置由固定 seed 生成，`y -= speed * delta`，`x += sin(t * freq + phase) * 3`；远景 `#BFD0EA` alpha 0.25，近景 `#FFD27A` alpha 0.45，叠加即近似 Add 混合 |
| 湿地倒影 | `draw_colored_polygon()` / `draw_rect()` | 把 entity 的像素块矩形按脚底 Y 做垂直镜像（`y' = 2*ground_y - y - h`），高度压缩 0.70，填原色 alpha 0.35；逐行加 `sin(t + row) * 0.03 * width` 的横向错位模拟水波 |
| 像素角色 | `draw_rect()` × 像素块 | 用一张 32×32 的二维色板索引数组（写在文档里的人工占位图案）逐格 `draw_rect(Rect2(px, py, 1, 1), palette[idx])`；**所有坐标 `round()` 到整数**，与低分辨率缓冲对齐 |
| Bloom | `draw_circle()` × 4~6 | 光源处画同心圆，半径 4/8/14/22/32，`#FFD27A` alpha 0.20/0.12/0.07/0.04/0.02，近似 glow 过阈效果 |
| 前景遮挡 | `draw_colored_polygon()` | 底部草丛/两侧柱剪影，填 `#0B1226`，alpha 0.9，制造纵深 |
| UI | `draw_rect()` | 底板 `Color("#0E1B33", 0.92)`，四边用 1px `#E8C479` 的 `draw_rect` 描线，角饰 8×8 小方块；文本用点阵字占位或直接画方块示意 |

### 7.3 视差与像素网格

```text
# 每层绘制前套用变换（伪代码，非交付代码）
for layer in layers:
    ox = round(-cam_x * layer.parallax)
    oy = round(-cam_y * layer.parallax * 0.3) if layer.id in ("bg_0_sky", "bg_1_far") else 0
    draw_set_transform(Vector2(ox, oy), 0.0, Vector2.ONE)
    draw_layer(layer)
draw_set_transform(Vector2.ZERO, 0.0, Vector2.ONE)   # UI 层前复位
```

- 背景层用连续色带/多边形 → 平滑；实体层用 1×1 矩形块 → 硬像素。两者在同一画布上即形成 HD-2D 对比。
- 所有实体坐标必须 `round()`；整帧先渲染到 640×360 的 `SubViewport`，再整数倍 Nearest 放大到屏幕（1 号落地）。
- 动画只需 `_draw()` 内读取 `Time.get_ticks_msec()` 驱动光尘、倒影波纹、bloom 呼吸，`queue_redraw()` 每帧调用。

| 层级 | 值 | 归属 | 本轮是否变更 |
