## 3. 真跑要求（本机工具链，零付费）

```bat
call D:\godogen_deps\env.cmd
python D:\godogen_assets\bin\godogen_win.py --cmd qwen-image generate "<prompt>" --quant nf4 --resolution 512 --steps 10 -o <项目内绝对路径>.png --json
```

- **已知硬限制**：`qwen-image` 权重 30.84 GiB > RTX 4060 Ti 显存，必须先 `--quant nf4` 或 CPU offload；本机至今**只跑通过 qwen-tts、没跑出过图**。首次出图就是本轮要验证的事。
- 一次只跑一个 GPU job，分钟级、长 timeout；stdout 只收路径 / JSON，stderr 存文件只在失败时读。
- 不要设 `HF_HUB_OFFLINE=1`；`huggingface.co` 直连被代理 502 挡住，靠 `env.cmd` 的 `HF_ENDPOINT=https://hf-mirror.com` + 本地缓存命中。
- `image/quantize.py` 是 **DiT 权重量化器，不是 256 色调色板量化器**；调色板收敛走 ComfyUI / Aseprite / ImageMagick。
- 出图后降到 128px 检查是否发糊；装饰 RGBA 层与 base 必须尺寸 / 帧序 / 坐标系 / seed / 降采样参数一致，非装饰区 `(0,0,0,0)` 全透明。
