# 00-接入指令（复制给每一路任务 AI）

把下面整段粘到 Rank-1 ~ Rank-4 各自的任务会话里，把 `<N>` 换成本路编号即可。**用户自行安排 4 路 AI 执行，主 AI 不代跑。**

---

你现在加入了协作群组 `HD2D-5AI`，成员为 HOST（主 AI）、Rank-1~Rank-4、OWNER（用户）。群的唯一真源是 `F:\Game\aierdengfahuan\teamwork\00-群聊总线.md`，规则全文见同目录 `00-群组通信协议.md`，请先读这两份。你所在工位仍是 `Rank-<N>\`，原有任务书与 `00-协作契约.md` 的约束全部不变。

接入后请这样做：

1. **开工只读一次**总线（读到末尾即可），看有没有 `TO` 含 `Rank-<N>` 或 `ALL` 的 `OPEN` 消息。**不要定时巡检、不要写探针脚本、不要扫别人工位**；只有用户明确说「刺探 / 巡检」才做一次只读确认。
2. 遇到以下四类事件，**在总线文件末尾追加一条消息**（只增不改，格式见第 3 条）：
   - 接口 I-1~I-6 有变更；
   - 本路里程碑（M0~M6）交付完成；
   - 被阻塞、需要别路配合；
   - 回应发给自己的 `OPEN` 消息（回应后另追加一条 `TYPE=通知` 说明该编号已 CLOSED，不要改原文）。
3. 消息格式（追加到文件末尾）：

   ```
   ## MSG-<YYYYMMDD-HHMM>-Rank-<N> · <YYYY-MM-DD HH:MM> · Rank-<N> → <TO>
   - TYPE: <接口变更|交付完成|阻塞求助|裁决请求|通知>
   - REF: <I-1~I-6 / M0~M6 / 文件路径 / ->
   - BODY: <一句话正文>
   - STATUS: OPEN
   ```

   `TO` 用 `ALL` / `HOST` / `OWNER` / `Rank-N`。编号带时间戳和你自己的编号，直接追加，不要抢号、不要改动别人的条目。
4. **不要发闲聊**，不要为了报进度反复刷屏；机密不进总线。
5. 企业微信群「艾尔登法环 · 5-AI 协作群」只是给用户看和插话的投影通道，**你在群里没有账号、也不需要去读群**；所有正式沟通落在总线。主 AI 只在用户说「同步到群」时把增量摘要推到群。
6. 接口争议以 `00-协作契约.md` 的 I-1~I-6 为准，群内讨论不构成决议；裁决由 HOST 在总线以 `TYPE=裁决` 发布。
