# 艾尔登法环HD2D-美术风格提案

> 版本 v1（待确认）｜ 2026-11-09 ｜ 设计分辨率 1280×720，像素层逻辑画布 128×128 ｜ 目标引擎 Godot 4.7.2 ｜ 档位 desktop / mobile ｜ 零付费、零外部素材生成服务
> 配套评审：`艾尔登法环HD2D-美术评审报告.md`（结论：重做）
> 基准图：`godot/assets/generated/r23_baseline/player_idle_v1.png`（透明底）/ `player_idle_v1_solid.png`（#FF00FF 纯色底复核版）

## 1. 风格锚点（逐字复用，生成时整段复制）

```
【风格锚点 v1 · HD-2D 受控像素】
画风：受控索引色像素画 —— 单帧 ≤16 色，128×128 原生逻辑画布（64×64 逻辑像素 ×2 nearest 放大），
      每个像素为有意识放置的硬边色块，禁止任何降采样与抗锯齿。
视角：正交 45° 俯视场景 + 正面四分之三角色，角色只做朝右单方向，左向由代码镜像。
光照：左上暖金主光 + 右下冷夜蓝补光，全项目光源方向统一；每种材质只做 3 阶明度（暗 / 中 / 亮）
      + 1 阶高光，禁止渐变光晕与多光源错位。
线宽：外轮廓统一 1 逻辑像素深色描边 #0A1020；内部靠色块分界，不重复描边；UI 金线固定 1px。
质感：哑光硬边平涂，无渐变、无 dithering、无纹理噪声、无高光反射、无半透明脏边。
比例：角色 5 头身，头部占整体 20%，肩宽约头宽 2.2 倍；武器与盾不得与躯干同明度同色相。
色彩倾向：深蓝夜景为底（背景 L 10–35），暖金只用于主光 / 金属 / UI 边框（L 60–95），
      冷蓝用于主体中间调（L 40–60）；同屏高饱和色 ≤3 种。
禁忌：① 禁止 512→128 或任何中间分辨率降采样路径；② 禁止单帧 >16 色、渐变、dithering、
      高频磨损噪点；③ 禁止把受版权保护 IP 的具体贴片或角色当作生成目标；
      ④ 禁止 UI 与特效明度高于角色高光，禁止贴图盖住判定区。
3D 补充：低多边形硬边、哑光材质、无 PBR 反射；地面只用 1 张 ≤12 色 tile，
      不做逐像素法线 / AO / 粗糙度通道。
```

## 2. 色彩板（色号统一定义一次，sRGB）

| 角色 | 色号 | 明度 L | 用途 |
|---|---|---:|---|
| 主色（钴蓝） | `#2C4C8C` | ≈45 | 主体中间调：盔甲、盾底、砖面 |
| 辅色（深蓝夜） | `#1B2A4A` | ≈22 | 暗部、背景天空、砖缝阴影 |
| 强调色（暖金） | `#C99A3A` | ≈65 | 主光、肩甲、UI 金线、金属装饰 |
| 最高亮（亮钢） | `#E8EDF2` | ≈92 | 武器、面甲高光、文字、强调 |
| 危险色（暗红） | `#B33A3A` | ≈40 | Boss、伤害、披风、红缨 |
| 阴影 / 描边 | `#0A1020` | ≈8 | 统一外轮廓、砖缝、接触阴影 |

派生色（仅用于亮面/高光过渡，仍计入 16 色上限）：`#3F6FC4`(L≈55)、`#79B4E8`(L≈72)、`#F2D07A`(L≈82)、`#C9D2E0`(L≈82)、`#6B4226`(L≈30)、`#35D0C0`(L≈70)、`#E8B98C`(肤色 L≈75)。

**硬规则**：主体与背景明度差 ≥2 档（背景 L 22 vs 主体亮面 L 65–92）；同族对象共用同一组辅色，只换主色区分个体；状态不能只靠颜色区分，须再带形状或图标差异。

## 3. 明度阶梯与背景 / 主体分离

| 层级 | L 区间 | 用途 | 本项目落点 |
|---|---:|---|---|
| 高光 | 80–95 | 金属 / 水面 / 强调 | `#E8EDF2`、`#F2D07A` |
| 主体亮面 | 60–80 | 受光面 | `#79B4E8`、暖金肩甲 |
| 主体中间调 | 40–60 | 固有色 | `#2C4C8C`、`#3F6FC4` |
| 主体暗部 | 20–40 | 背光面 | `#1B2A4A`、`#6B4226` |
| 背景 | 10–35 | 与主体错开 | 深蓝夜空、雾带、远山剪影 |
| 阴影 / 描边 | 5–20 | 统一轮廓 | `#0A1020` |

验证方法：成品转灰度，主体与背景仍清晰可分即合格；每批必须跑 10% / 25% 缩略图测试（见评审报告）。

## 4. 各资产类别表现约定

| 类别 | 尺寸 / 格式 | 透明 | 命名 | 表现约定 |
|---|---|---|---|---|
| 角色（玩家） | 128×128 RGBA，8 帧单行 1024×128 spritesheet | 必须 | `player_<pose>_v2.png` | 5 头身、1px 外描边、武器用亮钢阶；8 个 pose 共用同一 16 色板与同一光源方向 |
| Boss | 128×128 RGBA，3 帧单行 384×128 | 必须 | `boss_<pose>_v2.png` | 剪影比玩家宽 1.6 倍、牛角/武器轮廓优先；只换主色，辅色与玩家同族 |
| 地面 tile | 128×128 RGB（不透明） | 否 | `ground_tile_v2.png` | 4×4 大砖，每砖 3 阶明度，砖缝 1px `#0A1020`，零噪点；无缝边缘左右/上下像素完全一致 |
| 场景远景 | 1280×720 程序化色带 | 否 | `parallax_v2.gd` | 只用 3 段明度色带 + 剪影，禁止光尘噪点与渐变光晕 |
| UI | 九宫格切图，1px 金线 | 必须 | `ui_<name>_v2.png` | 深蓝底 `#1B2A4A` + 金线 `#C99A3A`，文字 `#E8EDF2`；明度不得高于角色高光 |
| 图标 | 32×32 或 64×64 | 必须 | `icon_<name>_v2.png` | 形状优先，禁用态除变灰外再加斜杠 |
| 特效 | 序列帧 ≤8 帧 @30 | 必须 | `fx_<name>_v2.png` | 硬边色块，禁止粒子噪点；避让 HUD 矩形 `x<730,y<220` 与角色判定区 |
| 动画 | 60fps 逻辑，动作帧 4/9/9=22（翻滚） | — | 沿用 `player_actions.tres` | 每 pose 至少 3 帧位移，禁止「单帧贴图换姿态」冒充动画 |
| 3D 层 | 低多边形硬边 | — | 沿用 `courtyard.tscn` | 地面只用 1 张 tile，`uv1_scale` 降到 4/2/1；`texture_filter=Nearest` |

**引擎导入（Godot 4.7.2）**：像素 PNG 关闭 mipmap、`texture_filter=Nearest`、压缩 `Lossless`、禁用 `fix_alpha_border`；`env` 类不要求透明通道；移动档降采样只允许改 viewport 缩放，不得重新生成低色数贴图。

## 5. 禁忌清单（每条对应具体失败表现）

1. **禁止降采样路径**：512→128 nearest 会让每块像素变成原图局部平均 → 失败表现就是本轮「马赛克」。
2. **禁止单帧 >16 色 / 渐变 / dithering / 高频磨损噪点**：失败表现为 10% 缩略图糊成一团、地面平铺成杂色。
3. **禁止 IP 复刻**：不生成受保护角色、装备、贴片的具体造型；DNF / 艾尔登法环只作为结构规律参考。
4. **禁止 UI / 特效比角色亮、禁止贴图盖判定区**：失败表现为远处看不清角色落点与攻击判定。
5. **禁止未确认锚点就批量放量**：风格锚点 v1 未确认前只出 1–2 张基准图。
6. **禁止覆盖旧版**：迭代一律 `_v1` → `_v2`，旧版保留供回溯。

## 6. 参考坐标（提取的是结构特征，不是生成目标）

| 参考 | 提取的结构特征 | 不提取 |
|---|---|---|
| 《八方旅人》HD-2D | 像素精灵 vs 平滑景深景深对比、暖金主光与冷夜雾强对比、体积光/光尘/湿地倒影/bloom 的**分层方式** | 具体场景、角色、UI 造型 |
| DNF NPK 贴片（本机参考） | 构图重心、明度阶梯、轮廓节奏、装备剪影的**可读性原则** | 任何具体贴片像素、角色脸/装备纹样、商业质感 |
| R23 失败素材（反面样本） | 「降采样 + 高色数 + 高频噪声」导致马赛克的**判据** | 不作为色板或质感来源 |

> 版权提示：DNF 与《艾尔登法环》均为受保护 IP；本项目同人开发，所有可见素材按本锚点原创生成，DNF 贴片仅本机参考、不进 pck / exe / apk，也不随仓库分发可识别商业贴片。

## 7. 第 1 批基准图产出计划（只出 1–2 张）

已产出并目视验证（**规格示意，非最终商用素材**）：

| 文件 | 规格 | 实测 | 缩略图测试 |
|---|---|---|---|
| `r23_baseline/player_idle_v1.png` | 128×128 RGBA，64×64 逻辑网格 ×2 nearest | **16 色**，亮度 L 9–243，透明底干净 | 25% 骑士/盾/剑/红缨清晰；10% 保留竖直剪影结构 |
| `r23_baseline/player_idle_v1_solid.png` | 同上，纯色底 #FF00FF 复核版 | 同上 | 用于检查透明边与半透明脏点 |

生成规格槽位（逐字复用，一次只变一个变量）：

```
BASE_CANVAS=128x128 ; LOGICAL_GRID=64x64 ; SCALE=2 NEAREST ; PALETTE=16色固定表
OUTLINE=1px #0A1020 ; LIGHT=左上暖金 ; SHADOW=右下冷蓝 ; ALPHA=硬边0/255，无半透明
POSE_SLOT=<idle|walk|run|roll|attack_light|attack_heavy|hitstun|death>
VARIATION=<仅改 pose 几何块，色板/光源/描边/比例一律不变>
```

下一批（**待用户确认锚点后**才放量）：`player_idle_v2`、`ground_tile_v2` 各 1 张，先跑色数 ≤16 / ≤12、10% 与 25% 缩略图测试、灰度明度分离三项校验，通过后再批量。

## 9. 收敛机制

- 版本号 `_v1` → `_v2`，旧版保留；只改指定部分，不顺手改配色或线宽。
- 已确认条目冻结；确需变更先说明会推翻哪几项。
- 连续两轮用户无实质修改意见 → 视为定稿，锚点升版并冻结。
- 每轮变更记录：改了什么 / 为什么 / 影响哪些已产出资产。
