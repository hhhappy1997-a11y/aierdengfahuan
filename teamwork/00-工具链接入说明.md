### 4.1 与「256 色 / 128bit」规格的对接（Rank-4 重点）

- **256 色**：`image/quantize.py` 是 DiT 权重量化脚本，**不是调色板量化器**；像素调色板收敛仍由 ComfyUI 管线 + Aseprite/ImageMagick 完成。Godogen 提供的是**素材后处理**：`grid_slice.py` 把 kit 图切成等尺寸帧、`find_loop_frame.py` 找循环帧、`rembg_matting.py` 兜底抠图。
- 小精灵经验（来自 `asset-gen/SKILL.md`）：1024px 降到 64px 会糊；**设计显示尺寸 ≥128px**、用粗平涂造型，或生成 kit 后切片。这与本项目 `128bit`（暂按 128px 基准画布理解）正好对齐。
- 一致性做法：先出一张 hero 素材，其余用 `qwen-image edit -i hero.png` 只改差异；方向左右会错，**只生成一个方向、运行时翻转**。

### 4.2 Godot 侧构建门禁（Rank-1 重点，来自 `godot-gdscript.md`）

```bash
godot --headless --import
godot --headless --check-only --script <changed>.gd
godot --headless --quit
```

- `project.godot` 的 `config_version` 按 `godot --version` 实测填写，**不要凭记忆硬编码**；3D 用 `Jolt Physics` + 固定 `physics_ticks_per_second`。
- GDScript 全静态类型；`:=` 遇到无类型接收者会失败，用 `absf/clampf/lerpf/maxi` 等带类型变体。
- 场景建议用 `extends SceneTree` 构建脚本在 `_initialize()` 里生成 `.tscn`（**先叶子后父级**，`owner` 链必须完整，pack 后 `instantiate()` 比对节点数再保存），避免手写 `.tscn` 静默丢节点。Rank-1 已有的手写骨架可保留作结构示意，但落工程时建议改走构建脚本。
- GLB 用 `MeshInstance3D` AABB 缩放 + 图元碰撞体，**不要** `create_trimesh_shape()`。
- 运行时 `SCRIPT ERROR` 只中断当前函数、退出码仍为 0，**必须 grep 日志**才算通过。

## 5. 调用规范（所有工位）

1. 统一入口：`python D:\godogen_assets\bin\godogen_win.py --cmd <tool> ... --json`（或 `bin/<tool>` 的 Windows 适配）。
2. **必须传 `-o` 指向项目内路径**，否则产物落在 `godogen_assets` 的 `outputs/`。
3. **一次只跑一个 GPU job**（`qwen-image` / `qwen-tts` / `gen-moves` 会各自加载模型），分钟级；用长 timeout 或后台，禁止并行调用。CPU 工具（`add-moves` / `grip-prop` / `lipsync`）可与一个 GPU job 重叠。
4. 输出契约：stdout 只有路径或 `--json` 的单个 JSON 对象，进度走 stderr；stderr 存文件，只在失败时读。
5. 资产清单要带 **in-game Size 列**（像素精灵写 `128x128 px`，音频写 `1.2 s one-shot`），否则引擎侧缩放必错。
6. 每张 PNG 都要人眼看；GLB 用 `asset-blender tools/render_glb.py` 渲染检查，音频看频谱。
