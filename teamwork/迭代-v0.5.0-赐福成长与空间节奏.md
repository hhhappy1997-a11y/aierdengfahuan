## 1. 核心循环诊断（Game Designer）

v0.4.0 的循环是「三波试炼 → 累积赐福点数 → 结算」。诊断出的新断点：**点数只进不出**，玩家拿到点数后没有消费、没有成长、没有再挑战的动机变化，长期钩子断裂；三波又都在同一庭院同一站位，缺空间节奏。

| 断点 | 本版补法 |
|---|---|
| 点数无出口 | 赐福成长：3 个永久增益（HP 上限 / 翻滚无敌 / 攻击力），点数兑换 |
| 长期动机断裂 | 余额 = `points − spent_points`，已购增益永久生效，重复挑战更轻松 |
| 三波空间无变化 | 每波远景色带 / 雾密度 / 地面色调 + 纵深站位 |
| 重启丢进度 | `SaveSystem` 占位接线，真实场景 `_ready()` 自动 `_load()` |
