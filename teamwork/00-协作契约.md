## 5. 技术约束（来自总纲 + 项目既定决策）

- Godot 4 标准版 / GDScript；角色用 `Hybrid2D3DSprite` / `Hybrid2D3DAnimatedSprite` 思路（像素→米缩放、底部中心锚定、自定义 AABB），**不自己造 billboard**。
- 地形为 3D 网格（非 TileMap）；像素化后处理走低分辨率渲染 + Nearest 放大。
- 像素图导入：lossless、关闭 mipmaps、`texture_filter = Nearest`、项目级 `default_texture_filter=0`。
- 视觉基调按《八方旅人》HD-2D：像素点阵角色 vs 平滑多层视差景深、体积光、光尘、湿地倒影、bloom、金线深蓝 UI、暖金光 × 冷夜雾强对比；核心是「像素精灵 vs 平滑景深」的对比，不是单纯像素风。
- **零外部依赖增量**：不引入任何付费素材、外部素材生成服务；美术只有「本地 ComfyUI」与「程序化 `_draw()` 占位 + 手工精修」两条路。不列云服务、不列花费确认项（总纲第 6 节「云 ComfyUI」分支按项目既定决策废弃，改为纯本地降级）。
- **刺探规则（全局，所有 AI）**：默认**不刺探** —— 不扫目录、不做进度巡检、不反复核对文件状态、不写探针 / 测量 / preflight 脚本；直接产出、直接真跑、用实际输出判断。**只有用户明确说「刺探 / 量一下 / 补读数 / 巡检」时**，才执行一次只读检查；用户没说就不要做。进度跟踪由主 AI 以事件驱动方式记入 `00-进度台账.md`。
- 每个里程碑都必须能自己上手玩；WorkBuddy 不替人做手感与审美判断。
- 密度优先于尺寸；隐藏墙不给任何提示；数据表改数值不改代码。

### 9.3 美术素材规格（I-5 资产交付口径真源 · R23 用户拍板修订 / R25 裁决 A15 统一口径）

> 本节即跨模块接口 **I-5（4 → 1）** 所交付 `assets/generated/<品类>/` 素材的规格真源。
> 2026-11-09 R23 按用户拍板口径「`128bit` + 256 色以上」与 DNF 合规边界修订**本节**；**2026-11-10 R25 裁决 A15**（用户选第 5 项视为确认美术风格提案 v1）把 I-5 色数口径由「256 色以上 / 单帧 ≥256」统一为「**项目级色库 ≥256 色、单帧强制 ≤16 色索引、RGBA 保 alpha、128px 基准画布**」。§3 跨模块接口表与其余历史条款一律不动。

- **所有美术素材统一用本地 ComfyUI 制作**（自建管线，**零付费** / 零外部服务，与项目既定决策一致）。程序化 `_draw()` 仅作 M0 占位与显存不足时的降级，**不是正式素材路线**；零付费口径不变，不引入任何付费素材或付费素材生成服务。
- **像素素材规格（R25 裁决 A15 统一口径；用户原文 `128bit` 歧义仍待确认）**：
  - **色数（两层口径，须同时满足）**：
    - **项目级色库 ≥256 色**：全项目共用一份**项目级色库 / 统一调色板**，色库规模 ≥256 色；这是**项目级下限**，不再以「≤256」封顶压缩色域。
    - **单帧强制 ≤16 色索引**：**每一帧**像素素材只允许使用**不超过 16 个色索引**（受控色板，消除 R23/R24 的马赛克观感）；这是**单帧上限**，与项目级色库下限不矛盾 —— 色库大全项目共享、单帧从中取 ≤16 色。
    - 原「256 色以上 / 单帧 ≥256」口径**废止**：既不再要求单帧 ≥256 色，也不再以 256 色作为单帧下限。
  - **画布：128px 基准画布不变**。逐帧 128×128、脚贴地等既有基准保持。
  - **RGBA 保 alpha**：素材继续走 RGBA、**保留透明通道（alpha）**；装饰层逐像素对齐与非装饰区全透明等既有规范不变。
  - **`128bit` 歧义：显式保留、待用户确认（A15 不消歧）**。该词来自用户原文，可能是「128px 画布尺寸」也可能是「位宽 / 色深」；**不自行改口径、不消歧、不编码进任何期望值、以用户为准**。当前落地仍按 **128px 基准画布 + 项目级色库 ≥256 色 / 单帧 ≤16 色索引 + RGBA 保 alpha** 理解，若与用户本意不符以用户后续确认为准。
- **DNF 资源合规边界（R23 用户拍板）**：DNF（`Neople` / 腾讯版权）NPK / 贴片等资源**仅可作本机开发期风格参考**，**不得进入 `pck` / `exe` / `apk` 任何发布包**，不得随仓库分发可识别的商业贴片；正式素材仍只走本地 ComfyUI 自制路线。合规登记见 `teamwork/Rank-3/DNF-COMPLIANCE-R23.md`。
