## 2. I-2 信号改挂 `GameEvents` autoload · 本轮收敛方式说明

  参数单个 `String`、击杀 flag 不双写均符合口径，但**未显式挂 `GameEvents` autoload**。

### 2.2 本轮收敛（既有件零改动）

- 按任务书-R4 §硬性约束「不改既有交付件内容（只追加 / 补齐）」与用户指令
  「R2/R3 已产出件一律不重做，只补齐本轮新增 / 缺失项」，**不改任何既有 `.gd` 一行**。
- 新增 `combat_event_bus.gd`（`class_name CombatEventBus`）作为 **2 号唯一的 I-2 对外发射点**：
  `report_defeat(defeat_id: String, is_boss: bool)` 直接 `emit_signal` 到
  `/root/GameEvents` autoload 的 `enemy_defeated` / `boss_defeated`（1 号注册、3 号实现
  `game_events.gd`，两个信号定义在该 autoload 上、参数单个 `String`）。

  降级为 `push_warning` 且**不回退本地信号**，避免双出口。

```
EnemyDirector.target_defeated / BossController 击杀
```

- 与 3 号《接口契约.md》§2.2「节点组 `combat_signal_bus` 优先 + `/root/GameEvents` 兼容」
  的发现顺序兼容：本轮把信号承载体**统一收敛为 GameEvents autoload**。
- `PlayerStateMachine` 上既有的同名信号**降级为模块内历史声明**（既有件零改动，保留供
  1 号 / UI 模块内订阅）；3 号只订阅 GameEvents、不重复订阅，避免双写。
