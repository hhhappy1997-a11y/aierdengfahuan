## 4. 建议（倾向性文字，仅供裁决参考）

**倾向方向 A（改 3 组 `max_resistance`、保持 N=8 不变）**，理由三点：

1. **口径一致**：与 `数据表schema.md` §5「`max_resistance >= threshold + gain × 8` 建议」及 §9
   E-8 式完全对齐，**不动校验器、不动文档**，不引入「×8 / ×5」口径漂移。
2. **符合项目既定决策**：契约 §5「数据表改数值不改代码」——只改 `.tres` 的 3 个数值字段。
3. **影响面最小**：不改 `threshold` / `gain` / 触发伤害 / 招式施加值，故**不改变异常触发难度曲线的
   前段**，只抬高「连续触发后抗性累积」的封顶；对 M5 Boss 手感扰动最小（手感判断仍归人）。

**保留意见（如实登记）**：

- 方向 A 会改既有落位件 `boss_01_margit.tres` 的数值，属「既有件」，须由总指挥明确授权后方可执行；
  2 号**本轮未改、不自行落盘**。
- 若总指挥认为「×8 样本次数」本身不合理（例如设计上只预期 4~5 次触发），则方向 B 更贴合设计意图，
  但必须同步修订 schema §5/§9 口径，2 号同样不代为决定。
- **最终数值、是否同步改口径、由哪一轮执行，一律由总指挥裁决。** 本表 ⑤ 列「建议」是
  `任务书-R9.md` 要求的文字建议，**不是选定值、不是实施结果**。
