## 4. `战斗系统设计.md` 必写要点

1. **玩家状态机**：idle / walk / run / roll / attack_light / attack_heavy / hitstun / death 的转移条件与优先级。
2. **翻滚无敌帧**：明确起手帧 / 无敌帧 / 恢复帧的帧数及所在数据表字段，无敌区间用左闭右开并给自洽等式（M1 验收「翻滚无敌帧正确」）。
3. **韧性与削韧（poise）**结算、处决触发条件；**异常状态积累**（出血 / 中毒 / 冻伤）的积累值、阈值、衰减、延迟、触发效果。
4. **伤害公式**：攻击力 × 招式倍率 × 阶段倍率 − 防御，逐项标注数据表字段来源；**禁止硬编码清单**。
5. **敌人追击 AI**：感知半径 / 丢失半径（含滞回）、追击速度、攻击距离、轮询间隔、加权抽取；与 `SpawnRequest`（I-3）的对接。
6. **Boss PhaseTransition**：HP 阈值 → 替换 `SpriteFrames` → 切换攻击表 → 播放过渡，禁止换场景；给出状态图。
7. **「改数值不改代码」保障机制**：表驱动字段清单 + 禁止硬编码清单 + 校验等式。
