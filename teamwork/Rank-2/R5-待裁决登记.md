3. **战斗语义**：E-8 是「抗性不溢出」自洽校验，约束异常状态在连续触发后抗性累积上限；数值如何落定会改变 bleed / poison / frost 的异常触发难度曲线，属数值设计裁决，2 号不代为判断。
4. **非阻塞性**：该冲突不影响三段门禁的脚本层通过（`SCRIPT ERROR` 0 命中）、不影响既有件零改动、不阻塞本轮收尾；但**集成前必须裁决**，否则数据层 3 项错误会随启动持续出现。
5. **范围边界**：修复动作涉及改 `.tres` 数值、改 `@export` 默认值或改 `数据表schema.md` §9 口径，均超出本轮「不擅改数值 / 不擅改口径」边界，需总指挥明确指令后方可执行。
