## 1. 战斗区总体空间规格（blockout 要素表）

> 三波共用**同一战斗区**（不切场景、不加载打断循环），靠生成点 / 预告位 / 退避带宽度 / 来敌方向 / 视野收束做节奏差异（GDD §4.4）。以下为 blockout 必须预留的空间要素，均**不写具体尺寸**。

| # | 空间要素 | 规格（Level Designer 口径） | 约束 / rationale（`[PLACEHOLDER]` 待校准） |
|---|---|---|---|
| S1 | **战斗区** | 一个连续、闭合、可读的平面战斗区；玩家与敌人始终处于同一可见画面内 | 尺度 `[PLACEHOLDER]`；过窄无退避、过宽丢压迫感；与 GDD §4.3「连续可退避带」共存 |
| S2 | **玩家初始位** | 每波读秒开始时玩家的固定落位，位于战斗区中轴、与任一生成点保持可读距离 | 距离 `[PLACEHOLDER]`；保证读秒窗口内玩家能自由移动定位退避带，不被生成点贴脸 |
| S3 | **敌人生成点** | 每波 1~N 个生成点，位于战斗区边缘 / 指定方向；生成点与退避带**分离、不重叠** | 数量 / 方位 `[PLACEHOLDER]`；逐波变化制造节奏（§4），但始终在视野内可见 |
| S4 | **预告位** | 读秒窗口内敌人「提前可见」的位置（轮廓 / 剪影 / 起手预告），与生成点关联、与 `enemy_id` / `move_weight` 对齐 | 预告提前量引用 `telegraph_sec` `[PLACEHOLDER]`；玩家受击前须能读出敌人类型与出招方向 |
| S5 | **退避带** | 战斗区内一圈 / 数条**连续可退避**的安全带：玩家从敌人近身位能靠翻滚 / 走位脱离到安全距离再回场 | 宽度逐波收窄（§4），但**每波都必须连续、无死角**；不带即死死角、不靠隐藏墙提示（契约 §5「隐藏墙不给任何提示」不适用于试炼区，试炼区必须可读） |
| S6 | **HUD 安全区** | 波次 HUD 标签（第 N/3 波 ｜ 赐福点数 ｜ 余额 ｜ 倒计时 ｜ 历史最佳）的屏幕占位区 | 避开既有赐福 HUD / 画质面板 / 底部战斗 HUD（Rank-1 任务单口径），**不遮挡退避带与敌人预告位**；`余额` 为 v0.5.0 新增只读标签（GDD §9.4） |
| S7 | **波间结算窗口位** | `WAVE_CLEARED → NEXT_WAVE` 短结算期间，点数 / 余额跳动与下一波预告的呈现位 | 不切场景、不挡退避带；具体时序由 Rank-1 状态机编排，本规格不定义时序数值 |

> **空间分层原则**：预告位（S4）在视野内、退避位（S5）在威胁范围外、HUD 安全区（S6）在屏幕边缘，三者**互不重叠**；生成点（S3）与退避带（S5）**分离**。这是 §2~§4 所有逐波变化都必须守住的底线。

## 2. 入场读秒与敌人可见预告（每波通用机制 + 逐波差异）

### 2.1 通用机制（三波一致，保证公平性下限）

- 进入试炼先 `IDLE → TELEGRAPH`，读秒时长引用 `telegraph_sec` `[PLACEHOLDER]`（Rank-2 `WAVE-TRIAL-TUNING.md`，逐波取值见 §4 表）。
- 读秒期间**不生成伤害判定**：玩家可自由移动、从 S2 初始位定位到 S5 退避带；HUD 的「倒计时 / 第 N/3 波 / 赐福点数 / 余额 / 历史最佳」同时点亮。
- 读秒窗口内把本波 `enemy_id` 对应敌人**提前可见**（S4 预告位）：轮廓 / 生成点 / 招式起手预告，预告内容与 Rank-2 数据表 `enemy_id` / `move_weight` 对齐。
- **可判性硬要求**：玩家在受击前能读出敌人类型与出招方向；高频招式（`move_weight` 高）必须先有可见前摇，避免「看不见就死」（GDD §1.2 / §4.2）。
- 读秒归零才进 `WAVE_ACTIVE`；读秒被中断（退出 / 依赖缺失）按 GDD §1.5 E4 / §9.5 G-E4 降级，不写 flag。
- 复用既有 `enemy_01_limgrave_soldier` / `boss_01_margit` 数据表 id，**不新增数据表、不新增敌人资源**（Rank-2 口径）。

### 2.2 逐波预告差异（预告不取消、只调信息量）

| 波 | 读秒时长引用 | 可见预告内容 | 预告信息量 | rationale |
|---|---|---|---|---|
| 第 1 波 | `telegraph_sec` 第 1 波行 `[PLACEHOLDER]` | 敌人类型 + 生成点 + 完整起手预告 | **最完整**（教学：把「读场」教给玩家） | 首波容错最高，让玩家建立「读秒→看预告→定位退避带」的动作范式 |
| 第 2 波 | 同表第 2 波行 `[PLACEHOLDER]` | 保留起手预告，叠加来敌方向 / 组合变化提示 | **中等**（加压：逼玩家重新读场，不靠背板） | 方向变化本身是空间预告，必须先可见再生效 |
| 第 3 波 | 同表第 3 波行 `[PLACEHOLDER]` | 起手预告**仍可见、不取消** | **精简但不减公平性**（收束：只保留判定必需信息） | 收束波空间最紧，但公平性下限不因「最难关」而被牺牲 |

> **三波共同底线**：**任何一波都不得取消起手预告**。难度提升靠空间（§5），不靠「藏信息」。

## 3. 站位与退避空间（Level Designer 可玩性规格）

### 3.1 玩家站位

- **初始位 S2**：每波读秒开始固定落位，中轴、与生成点保持可读距离 `[PLACEHOLDER]`；读秒内玩家自由移动，不锁位移。
- **交战站位**：玩家在「敌人近身位 ↔ 退避带」之间做位置 / 时机决策；输入沿用既有移动 / 翻滚 / 攻击，**不新增输入、不改既有战斗件**（GDD §1.3）。
- **回场路径**：从退避带回到敌人威胁范围须有连续路径，不被地形 / HUD / 生成点截断。

### 3.2 退避空间（S5）

- **连续可退避**：从任意敌人近身位，玩家能靠翻滚 / 走位脱离到安全距离再回场；退避带逐波收窄但**每波都连续、无死角**。
- **不带即死死角**：任何位置都不允许「进得去、出不来」；试炼区**必须可读**，不依赖隐藏墙提示或隐藏安全点（契约 §5 的隐藏墙规则不适用于此）。
- **生成点 / 退避带分离**：S3 与 S5 不重叠；预告位 S4 在视野内、退避位 S5 在威胁范围外。
- **与 HUD 解耦**：S6 HUD 安全区不遮挡退避带与敌人预告位；v0.5.0 新增的「余额」标签同样落在既有占位之外。
- **与永久增益解耦（v0.5.0 新增说明）**：GDD §9 的永久增益（HP 上限 / 翻滚无敌窗口 / 攻击力）改变的是**玩家能力**，**不改变 S1~S7 任何空间规格**；「重复挑战更轻松」来自玩家变强，而非退避带变宽或敌人数值调弱（§5）。

### 3.3 站位 / 退避验收口径（规格级，非脚本）

| # | 判定项 | 期望 |
|---|---|---|
| SP-A1 | 读秒窗口内玩家能否从 S2 走到 S5 任一点 | 能，且无伤害判定 |
| SP-A2 | 任一敌人近身位是否存在连续退避路径 | 存在，无死角 |
| SP-A3 | S3 / S4 / S5 / S6 是否互不重叠 | 是 |
| SP-A4 | 高频招式是否先有可见前摇再生效 | 是（§2.1 可判性） |
| SP-A5 | 三波是否共用同一战斗区、不切场景 | 是（GDD §4.4） |

> 以上为**规格判定项**，供 Rank-1 接线与用户侧人工试玩核对；本规格**不写验证脚本、不代跑、不代验**（真跑载体 `verify_grace_flags_v050.gd` 只验 flag 口径，不验空间）。

## 5. 难度空间优先于数值缩放（本规格核心论点）

> **一句话口径**：逐波抬压**优先靠空间**（来敌方向 / 生成点数量 / 退避带宽度 / 预告可读性 / 视野收束），数值（`hp_multiplier` / `move_weight` / `time_limit_sec`）只做**微调兜底**，不是主要难度杠杆。

| 维度 | 空间杠杆（**优先**） | 数值杠杆（**兜底 / 微调**） |
|---|---|---|
| 第 1→2 波 | 单方向 → 换向 / 多生成点；退避带最宽 → 中等 | `hp_multiplier` / `move_weight` 第 2 波 `[PLACEHOLDER]` 小幅抬升 |
| 第 2→3 波 | 退避带中等 → 最窄；视野 / 站位余地收束；组合最复杂 | 同表第 3 波 `[PLACEHOLDER]` 行 |
| 公平性 | 预告**始终可见**、退避带**始终连续**、无死角 | 时限 / 倍率维持可读下限，不靠「看不见就死」提难度 |

**为什么空间优先（rationale，写清不拍脑袋）**：

1. **可读、可判、可退避**：空间变化是玩家**看得见**的（方向变了、退避带窄了、生成点多了），玩家能当场调整站位与时机；数值放大（血量 / 伤害 / 时限）若过猛，会退化为「看不懂就死」或「磨血磨到超时」，违背 GDD §1.2「可预期的紧张」核心情绪。
2. **公平性不依赖背板**：GDD §4.2 要求高频招式先有可见前摇；空间杠杆把「难」放在「读场与走位」上，而非「背下倍率数字」上，重复挑战的价值才是「练会读场」而非「背表」。
3. **调空间不改存档 / 不触发迁移**：空间规格属 Rank-1 场景编排，调向 / 调退避带不动 `flags`、不动 `schema_version`、不触发 §4.7 迁移；与 GDD §5「数据表改数值不改代码」互补而非冲突 —— 数值仍只在 Rank-2 `[PLACEHOLDER]` 表内微调。
4. **与 v0.5.0 成长解耦**：玩家变强（永久增益）后，难度曲线**不用改空间、也不用改数值**即可自然「更轻松」；若反过来靠数值缩放，则每次调增益都要重平衡倍率，破坏 R26 §5「曲线与存档解耦」。
5. **可校准**：空间量全部 `[PLACEHOLDER]`，人工试玩后按「第 1 波必须可在时限内完成（GDD F2）/ 三波全清不得过快（F3）」只调占位值，不改本规格结构。

> **与 GDD §5 难度曲线的关系**：GDD §5 描述「逐波单调抬压、每波保留可读窗口」的**曲线形态**（以 Rank-2 `[PLACEHOLDER]` 表为准）；本节补充其**实现优先级**（空间 > 数值）。二者不冲突：数值表仍单调抬压，但抬压幅度以「不破坏可读窗口」为上限，主要难度差异由 §4 blockout 的空间梯度承担。
