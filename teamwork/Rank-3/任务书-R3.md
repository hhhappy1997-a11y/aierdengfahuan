```bash
D:\Godot\Godot_v4.7.2-stable_win64.exe --headless --check-only --script <changed>.gd
```

语音（本机已实跑通过，零付费）：

```bat

python D:\godogen_assets\bin\godogen_win.py --cmd qwen-tts batch <voice_manifest.json 绝对路径> --relative-to-manifest --json
```

- 先 `call env.cmd`；**不要设 `HF_HUB_OFFLINE=1`**（上游 `from_pretrained` 仍访问 model API，offline 会直接抛 `OfflineModeIsEnabled`）。

- `-o` 必须指向项目内；产物要同步登记进语音键表，避免「有 WAV 但游戏不知道」。
- `stable-audio` 是 gated 模型（403，无 token）**不可用**，音效改本地合成 / `loop_audio.py`，不申请、不绕过、不列付费项。
